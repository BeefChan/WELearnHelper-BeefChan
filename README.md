基于 [SSmJaE/WELearnHelper](https://github.com/SSmJaE/WELearnHelper) **1.1.0** 继续修改，主要修复刷时长相关功能失效、重新适配自动答题的多种题型，并新增刷题范围、自动等待及自动下一节等功能。

**当前版本：1.3.4。** 原版基线为 1.1.0。项目地址：<https://github.com/BeefChan/WELearnHelper-BeefChan>

> **本版本未经过大规模充分测试。** 覆盖的教材、题型和页面结构有限，可能存在未适配或回归问题；请先在少量章节验证，确认符合预期后再批量使用。

## 修复了哪些问题

### 1. 刷时长相关功能失效

修复自动挂机、定时切换、循环及随机延时相关逻辑中的问题，包括：

- 设置尚未读取完成就启动定时任务，导致开关或时间设置不生效。
- 课程页面地址大小写差异导致未识别学习页面。
- 切换时间以字符串保存、数值异常，导致定时不正常。
- 一次切换异常导致后续定时流程中断。
- 当前章节识别错误、不同单元同名章节被误判为未切换。
- 所选范围末尾停止、单节循环和重复切换相关问题。

这里修复的是**插件的挂机及切换逻辑**；实际学习时长、完成状态和成绩仍由平台记录，不保证挂着页面就一定计入有效时长。

### 2. 自动答题重新适配多种题型

针对已适配课件，对多类题目的处理方式做了重新适配和修复：

| 题型 | 适配 / 修复内容 |
| --- | --- |
| 普通填空、可编辑填空 | 改善填入、组件就绪检测及课件数据同步 |
| 选词填空、不可直接输入的词库空格 | 修复只改页面显示、实际答案模型未更新的问题 |
| 多空格组合题 | 按各空格对应的答案结构处理 |
| 下拉选择题 | 按课件选项 / 答案键设置，而非仅改显示文字 |
| 选择、判断题 | 调整对应组件的答案写入与状态处理 |
| 连线 / 配对题 | 修复处理异常，按课件对应关系执行 |

**重新适配多种题型不等于支持所有教材、所有题目。** 口语、录音、跟读、开放式写作及没有可靠标准答案的题型仍可能需要手动完成；默认填空内容也不等于正确答案。

### 3. 其他 Bug 修复

- 修复页面组件尚未加载就开始答题、同页重复处理等问题。
- 修复真实课程目录使用“同级列表＋层级编号”时分组错乱。
- 修复主页面和已经打开的课件 iframe 之间设置不同步。
- 修复本节已答完后再开启全自动，后续流程不继续。
- 修复嵌套课件的完成通知被当作旧页面通知而忽略。
- 加入完成通知去重、取消等待、手动换章后的状态检查。
- 改善范围保存、跨标签页选择同步、目录延迟加载和日志提示。

## 新增了哪些功能

| 新增功能 | 用途 |
| --- | --- |
| **刷题范围面板** | 按“单元 → 技能 → 子模块 → 练习”选择要处理的章节 |
| **分组勾选与半选状态** | 整组选中 / 取消，直观看到部分选择；支持全选、全不选和恢复默认 |
| **按课程 / 班级保存选择** | 刷新后保留选择，后续自动切换跳过未勾选章节 |
| **全自动组合流程** | 自动答题 → 按设置等待 → 尝试自动提交 → 自动下一节 |
| **媒体时长＋随机等待** | 按本页可读取的音视频时长加随机时间等待，并设置等待上限 |
| **自动提交前检查** | 检查课件进度与可判定答案状态；未确认完成 / 正确时跳过提交 |
| **等待期间自动播放媒体** | 可选静音播放，是否成功受浏览器播放策略影响 |
| **自动切换控制与防重复** | 关闭全自动或手动换章后，取消尚未执行的切换，减少重复通知造成的跳页 |
| **新版关于与使用引导** | 悬浮窗明确展示 1.3.4、原作者、BeefChan 和 AI 协作署名，并提供可展开的操作引导 |
| **整理后的悬浮窗 UI** | 增加运行模式和日志数量提示；设置分类改为适合窄屏的标签栏；统一控件、范围面板和键盘焦点样式 |

原版已有的自动答题、自动挂机、循环与随机延时，在本分支中是**修复 / 增强**，不是声称全部由本分支首次实现。

## 安装与更新

**推荐方式：下载 [Releases](https://github.com/BeefChan/WELearnHelper-BeefChan/releases) 里的 `WELearnHelper-1.3.4.zip`。** 按 Edge / Chrome 分步说明和故障排查见[完整安装说明](docs/INSTALL.md)。

1. 解压安装包，记住解压目录（安装后不要移动或删除）。
2. Edge 打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
3. 开启「开发人员模式 / 开发者模式」。
4. 点击「加载解压缩的扩展 / 加载已解压的扩展程序」，选择**直接包含 `manifest.json`** 的文件夹。
5. 停用旧版或重复安装的助手，避免多个版本同时运行。
6. 打开课程学习页面，刷新整个页面，检查悬浮窗「关于」中的版本是否为 **1.3.4**。

从源码构建安装包：

```powershell
cd upstream/v1.1.0
npm install
npm run build:crx   # 产出 dist/ 下的 index.js、inject.js、content.js、background.js
npm run package     # 生成 dist/manifest.json 与 icon.png，并打包 zip
```

更新已安装的扩展：替换文件 → 扩展管理页点击「重新加载」→ 刷新整个课程页面。**只刷新内部课件 iframe 不足以更新主页面脚本。**

## 详细使用方法

### 第一步：先选范围

1. 进入带章节目录的课程学习页，而不是仅停留在课程列表首页。
2. 点击右下角 **“刷题范围”**。
3. 可以先点“全不选”，再勾选需要的单元、听力 / 阅读等技能组、子模块或单个练习。
4. 父级复选框显示半选状态，表示该组只有部分练习选中；选择后自动保存。
5. **手动进入所选范围的起始章节**，再开启所需模式。

范围只控制后续自动切换：不会撤销当前已经打开、填写或提交的题目。全不选时停止切换；未开启循环时，到所选范围末尾停止。如果只选了当前章节之前的内容，应先手动进入起点。

### 模式 A：只自动填答案，自己检查和提交

1. 在设置“练习”中开启 **自动答题**。
2. 保持 **全自动刷题关闭**，同时关闭“自动挂机”，避免自动离开本节。
3. 按需开启“显示参考”，观察答案和日志。
4. 人工检查后，用课程页面自身的按钮提交或切换。

这是首次使用某本教材时更适合排查兼容性的方式。

### 模式 B：自动答题、等待、提交并切换

1. 选好范围，进入起始章节。
2. 开启 **自动答题** 和 **全自动刷题**。
3. 按需开启 **自动提交**；关闭后不会主动提交，但仍可能按全自动流程继续切页。
4. 设置“自动等待”“等待计入媒体时长”和随机等待上下限。
5. 查看日志：本节处理 → 等待时间 → 提交成功 / 跳过提交 → 准备切换。
6. 无需再启用“自动挂机”；全自动模式由本节处理流程负责切换。

**注意：**
- 开启自动等待时，答完不会立刻切页；等待时间以日志为准。
- 未完成的主观题、未确认正确的答案或缺失提交按钮，可能导致跳过提交后继续切页；这不等于该节已达标。
- 自动提交会触发平台提交，可能不可撤销。建议先用少量练习验证，别直接放着整本运行。

### 模式 C：仅刷时长 / 定时切换

1. 选好范围并进入起始章节。
2. 关闭 **全自动刷题**；不需要填答案时也关闭 **自动答题**。
3. 在“时长相关”中开启 **自动挂机**。
4. 设置 **切换下限 / 切换上限**，单位是**分钟**，不是秒。
5. 开启“随机延时”时，在上下限之间随机取值；关闭时固定使用上限。
6. 开启“循环挂机”时，到末尾尝试回到所选范围开头；关闭时结束一轮后停止。
7. 观察切换日志，并在平台学习记录中核对是否有效计时。

### 重要设置速查

下表为代码默认值；已保存的个人设置不会自动重置。

| 设置 | 默认值 / 单位 | 说明 |
| --- | --- | --- |
| 自动答题 | 关 | 自动填写已适配题目 |
| 答题间隔 | 1000 毫秒 | 影响自动答题节奏，不是章节停留时间 |
| 自动提交 | 开 | 在全自动流程中，满足检查条件时尝试提交 |
| 全自动刷题 | 关 | 需同时开启自动答题 |
| 全自动切换间隔 | 3 秒 | 本节处理后追加的切换等待 |
| 自动等待 | 开 | 开启后先等待，再提交 / 切换 |
| 等待计入媒体时长 | 开 | 累加本页可读取的音视频时长 |
| 随机等待下限 / 上限 | 60 / 180 秒 | 额外随机等待时间 |
| 等待总上限 | 90 分钟 | 限制媒体时长＋随机等待的总量 |
| 自动播放媒体 | 关 | 等待时尝试静音播放，可被浏览器拦截 |
| 自动挂机 | 关 | 按分钟间隔定时切页 |
| 切换下限 / 上限 | 5 / 10 分钟 | 仅定时挂机模式使用 |
| 随机延时 | 关 | 关闭时固定取切换上限 |
| 循环挂机 | 关 | 到所选末尾是否尝试循环 |

### 暂停、停止与常见问题

- **停止全自动：** 关闭“全自动刷题”；若不希望继续填答案，再关闭“自动答题”。
- **停止定时切换：** 关闭“自动挂机”。同时运行过其他模式时，检查对应开关也已关闭。
- **答完不切页：** 检查是否仍在自动等待、是否同时开启自动答题与全自动、后面是否还有勾选章节、是否已到范围末尾；更新后要刷新整个课程页。
- **时长没有增加：** 先看是否按期切页，再检查平台要求及学习记录；插件不能保证平台认可每次停留。
- **有些题没填：** 确认课件加载完成；主观题、录音及未适配题型应手动完成，不要把默认填空当正确答案。
- **找不到范围按钮：** 确认处于课程学习主页面、有章节目录，并已启用扩展；查看是否被另一版本覆盖。
- **停止后答案还在：** 停止开关只取消后续动作，不撤销已填入或已提交的内容。
