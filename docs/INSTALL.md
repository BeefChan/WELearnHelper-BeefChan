# WELearnHelper 1.33 安装说明

本文对应 BeefChan 非官方修复版 **1.33**（扩展清单版本 **1.3.3**）。原作者为 SSmJaE；安装后显示的版本和署名可在助手“关于”页查看。

## 下载方式

使用已发布安装包时，下载：

`WELearnHelper-1.3.3-BeefChan-UI-r3.zip`

解压后找到直接包含 `manifest.json`、`index.js` 和 `ui.css` 的目录。不要在扩展页面选择 ZIP 压缩包本身。

如果是从 GitHub 下载源码：点击 `Code` → `Download ZIP` 并解压，然后选择仓库内的 **`src` 文件夹**。`src` 中必须包含 `manifest.json`。

## Microsoft Edge 安装

1. 解压安装包到一个固定位置。不要只打开 ZIP 浏览文件，也不要安装完成后移动或删除这个目录。
2. 在 Edge 地址栏打开 `edge://extensions/`。
3. 打开页面左下角或右上角的「开发人员模式」。
4. 点击「加载解压缩的扩展」。
5. 选择解压后直接包含 `manifest.json` 的文件夹；若使用源码下载，则选择项目的 `src` 文件夹。
6. 确认扩展列表出现“WELearn网课助手”。
7. 打开或刷新整个 WE Learn 课程学习页面。课程页右下角应出现助手入口和「刷题范围」按钮。
8. 在助手窗口的关于页面确认版本为 **1.33（1.3.3）**。

## Google Chrome 安装

1. 解压安装包到固定位置。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择直接包含 `manifest.json` 的解压目录；源码方式则选择 `src` 文件夹。
6. 确认扩展已启用，然后刷新整个课程页面。

## 更新到新版本

1. 下载并解压新版本到一个新目录。
2. 打开浏览器扩展管理页，停用或移除旧版本，避免同一页面同时运行多个助手副本。
3. 点击「加载解压缩的扩展 / 加载已解压的扩展程序」，选择新版本目录；如果浏览器保留了原扩展条目，也可以先在原条目点重新加载并确认其目录已更新。
4. 刷新课程主页面，确保页面和课件 iframe 都重新载入扩展脚本。
5. 打开关于页检查版本。
6. 确认新版正常后，再删除旧文件夹。

仅刷新课程内部的课件 iframe 不一定会更新主页面脚本。源码目录开发更新时，在 `edge://extensions/` 或 `chrome://extensions/` 点击扩展卡片的重新加载按钮，然后刷新课程主页面。

## 首次使用建议

1. 先进入具体课程的学习页面，确认助手入口出现。
2. 打开「刷题范围」，选好要处理的单元或练习；选择会保存到该课程 / 班级。
3. 首次使用先只开启「自动答题」，观察少量已适配题型和日志。
4. 确认无误后，再按需开启「全自动刷题」或「自动挂机」。
5. 全自动模式开启自动等待时，页面会先等待媒体时长和随机时间；检查日志中的等待与切换提示。
6. 自动提交可能无法撤销。未适配、录音、口语和主观题请人工处理；不要将默认填空内容当成正确答案。

## 常见问题

### 点击“加载解压缩的扩展”后没有看到文件

在文件选择对话框中选目录，而不是 ZIP 文件；使用源码时选择 `src` 目录，不是仓库根目录。

### 提示找不到 manifest.json

目录选错了。打开选中的目录，确认其中直接有 `manifest.json`。安装包解压后，可能需要再进入一级同名目录。

### 扩展已加载但课程页没有助手

确认扩展已启用，页面属于支持的 SFLEP / WE Learn 课程页面。重新加载扩展后刷新整个课程页面，而不是只刷新 iframe。检查页面是否有章节目录；刷题范围按钮只在课程学习页面显示。

### 自动切换或某些题型没有反应

确认所需开关已启用并查看助手日志。全自动刷题需要同时开启自动答题；自动等待未结束时不会立即切换。不同教材及口语、录音、主观题的适配情况不同。
